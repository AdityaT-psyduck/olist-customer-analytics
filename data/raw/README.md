# Raw data

Place the Olist CSV files in this folder. They are intentionally not committed to Git (see `.gitignore`).

1. Download the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) from Kaggle.
2. Unzip the archive into this directory.

The notebooks use the following files:

```text
olist_customers_dataset.csv
olist_orders_dataset.csv
olist_order_payments_dataset.csv
olist_order_reviews_dataset.csv
olist_order_items_dataset.csv
olist_products_dataset.csv
olist_sellers_dataset.csv
product_category_name_translation.csv
```

The Kaggle archive also includes `olist_geolocation_dataset.csv`, which is not used in this project but can stay in the folder if downloaded.
